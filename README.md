# Claude Code Study

A personal study repository for exploring how Claude Code plugins consume language servers through the Language Server Protocol (LSP). It collects reference material and worked setup notes for wiring up servers such as `pyright` and `typescript-language-server` so they can be revisited offline.

## Contents

- [lsp-guide.html](./lsp-guide.html) — A self-contained practical guide to the Language Server Protocol and how Claude Code plugins turn language servers into in-editor code intelligence.
